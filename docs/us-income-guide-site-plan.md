# 美国赚钱指南（`us-income-guide`）站点规划

| 项目 | 说明 |
|------|------|
| 建议站名（中文） | 美国赚钱指南 |
| 英文目录/包名 | `us-income-guide` |
| 技术归属 | Astro monorepo，`apps/us-income-guide` |
| 语言 | 全中文正文；URL slug 可对齐英文或拼音，上线前统一一次 |
| 内容红线 | **克制、真实、合规**；不出现快速暴富、保证收入、逃税、灰产、刷单、博彩或无法验证的赚钱承诺 |

> **规划阶段说明**：本文档仅描述信息与架构规划，不涉及工程实现。**不替换** massage-growth / medspa-guide 的职责边界；工程落地时再单独拆任务（新建 app、SEO、RSS、站内搜等）。

## 1. 网站定位

- **一句话**：面向在美国生活、工作、创业或做副业的中文读者，提供**可对照现实检验**的路径梳理、自检清单和行业观察——帮助读者建立决策框架，而不是替读者做决定。
- **不是什么**：
  - 不是「致富密训」「躺赚」「月入 X 万」的营销站；
  - 不提供具体报税、记账、法务、签证、移民路径或证券投资指令；
  - 不代收费用、不卖「包过」课程、不承诺任何收入或职业结果。
- **是什么**：
  - 信息架构清晰的**中文入口百科 + 指南 + 模板**；
  - 强调**平台规则、劳动法规与税务合规需自行向官方与持证专业人士核实**；
  - 把「在美国获得收入」拆成可理解的模块：路径选择、时间投入、风险边界、信息来源、复查节奏。

## 2. 目标用户

| 用户群 | 典型场景 | 我们提供的价值 |
|--------|----------|----------------|
| 在美华人 / 新移民 | 初到美国，对收入形态、平台与合规边界不熟 | 概念框架、路径地图、官方信息入口提示 |
| 留学生（持合法工作许可前提下） | 在校内外寻找合法收入机会 | 仅讨论**许可范围内**的常见路径与风险意识，强调以学校 / DSO / 官方为准 |
| W-2 上班族 | 想增加收入或转型 | 副业与技能变现的**评估维度**，不承诺副业收入 |
| 1099 / 自由职业者 | 客户来源不稳定 | 接单、合同与沟通的可执行习惯，**不提供税务申报指导** |
| 本地服务从业者 | 清洁、搬家、维修、照护等 | 获客与定价的**原则性**讨论；禁止灰产接单教程 |
| 有意轻创业人群 | LLC、独立承包商等字眼常出现 | 仅提供「需要问什么问题」的检查清单；**不写注册与税务操作步骤替代品** |

所有内容默认读者应自行核对：签证/工卡状态、州法、联邦法、平台 ToS、以及当年税务规则。

## 3. 与 massage-growth、medspa-guide 的差异

| 维度 | massage-growth | medspa-guide | **us-income-guide** |
|------|----------------|----------------|---------------------|
| 垂直领域 | 按摩店本地营销 | Med Spa / 医美诊所营销 | **在美收入与工作形态** |
| 决策后果 | 经营与获客 | 医疗合规更敏感 | **财务、税务、劳动法、签证**交叉敏感 |
| 语气 | 可操作营销动作 | 专业营销 + 合规提示 | **更强克制**：框架、自检、可信来源引用 |
| 英文占比 | 站名中英混排 | 以英文主业为主（当前） | **全中文** |
| 「案例」写法 | 行业拆解 hypothetical | hypothetical | **禁止编造客户回本**；案例页仅教学法与认知偏误拆解 |
| 报告 | 方法论 / 本地化 | 行业报告占位 | **单份方法论框架报告**，不出现假数据仪表盘 |

三台站并列时，`us-income-guide` 的编辑标准应视为**财经与合规敏感度最高**，审校流程应单独一栏（见第 15 节）。

## 4. 视觉风格

- **基调**：冷静、可读、少一点「暴富红」和金融诈骗风。让读者感觉像「负责任的编辑部」，而不是导流号。
- **色彩建议**：
  - 主色：深蓝 / 石板蓝（可信、稳重）；
  - 点缀：单色点缀即可（克制金或青绿选一，避免同时使用多种高饱和度促销色）。
- **字体与排版**：中文优先系统栈 + Web 可读字体备用；正文行宽适中；列表与卡片用于拆解复杂概念。
- **组件气质**：少用夸张 CTA banner；多用「延伸阅读」「自检问题」「风险提示」模块化区块。
- **图标/插图**：线性图标、示意图为主；避免出现「钞票雨」「豪车」类隐喻。

## 6. 首页结构（建议版块顺序）

1. **首屏**：站名 + 一句价值主张（强调「框架与自检，不承诺结果」）。
2. **信任条**：编辑部原则三则（不真实数据、不推荐灰产、不替代专业人士）。
3. **六大入口卡片**：对齐主导航六项，各 2 行摘要 + 跳转。
4. **编辑精选指南**：从 28 篇中轮播 6 篇「新手必读」（可人工维护列表）。
5. **模板 / 清单**：卡片链到 6 个模板落地页。
6. **方法论报告**：单卡片 → `/reports/us-income-pathways-framework/`
7. **案例拆解**：2 张卡片 → 案例页（教学设计向）。
8. **信任页面快捷链接**：免责声明、编辑政策、联系方式。
9. **订阅 / RSS**（可选，工程阶段再定）。
10. **Footer**：全站次级导航 + 免责声明摘要。

首页文案需固定出现类似提示：**本平台内容仅供教育与信息参考；涉及税务、法律、移民与投资风险，请咨询持证专业人士并以官方为准。**

## 14. 不允许出现的内容

- 明示或暗示：**稳赚、包赚、躺赚、躺平暴富、财务自由速成**。  
- 任何**可操作逃税、避税猫腻、阴阳合同、现金不报**教唆。  
- 灰产：**刷单炒信、洗钱、倒卖个人信息、未取得许可的金融拉人头、境外博彩**。
